## 📝 Правила ведения репозитория

- **Коммит каждый день** — даже если маленький. Пустой день = коммит с заметкой `docs: day-off`.
- **Формат коммитов:** `phase-N: краткое описание` (например: `phase-1: добавлены 3 баг-репорта SauceDemo`).
- **PROGRESS.md обновляется каждую неделю** — отмечай ✅ выполненные пункты.
- **Если застрял** — пиши в заметку `phase-X/notes.md`, что именно непонятно.
