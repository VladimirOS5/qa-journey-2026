# 🚀 QA Journey 2026: От Trainee до Junior++

## Цель
Достичь уровня **Junior++ / почти Middle** QA-инженера за 20 недель интенсивного обучения + 1 месяц практики.

## Фокус
- Ручное тестирование (тест-дизайн, баг-репорты, Jira)
- Автоматизация: UI (Selenium/Pytest), API (Requests), Mobile (Appium)
- DevOps-интеграция: CI/CD (GitHub Actions), Docker, Allure Report
- Soft Skills: аналитика требований, участие в команде, документация

## Структура обучения
- неделя 1: Основы QA, Shift Left/Right, TestOps
- неделя 2: Тест-дизайн, тестирование требований, Jira
- неделя 3: API тестирование (REST, GraphQL, Async)
- неделя 4-5: UI автоматизация (Python, Selenium, POM, Allure)
- неделя 6: API автоматизация (Requests, jsonschema)
- неделя 7: Тестирование БД (SQL, интеграция с автотестами)
- неделя 8: Performance (JMeter)
- неделя 9: Security (OWASP ZAP)
- неделя 10: Mobile (Appium)
- неделя 11-12: Продвинутое API, Contract Testing (Pact), Data Testing
- неделя 13: DevOps (Docker, SLI/SLO, Shift Right)
- неделя 14: Архитектура тест-фреймворка (SOLID, POM vs Screenplay)
- неделя 15-17: Финальный проект (50+ UI, 40+ API тестов, CI/CD)
- неделя 18-19: Подготовка к собеседованиям, портфолио
- месяц практики: Стажировки, open-source, собеседования
