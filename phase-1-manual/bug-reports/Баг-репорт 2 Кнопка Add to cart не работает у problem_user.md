# BUG-002: Кнопка "Add to cart" не добавляет товар для problem_user

**Severity:** Critical  
**Priority:** High

## Описание
Для пользователя `problem_user` кнопка "Add to cart" не добавляет товар в корзину или не меняет своё состояние на "Remove".

## Шаги воспроизведения
1. Войти под `problem_user` / `secret_sauce`
2. Нажать "Add to cart" на любом товаре
3. Проверить иконку корзины (правый верхний угол)

## Ожидаемый результат
- Товар добавлен в корзину
- Кнопка изменилась на "Remove"
- Иконка корзины показывает "1"

## Фактический результат
- Товар не добавляется в корзину
- Кнопка остаётся "Add to cart"
- Иконка корзины пуста

## Окружение
- Браузер: Chrome 126
- ОС: Windows 11
