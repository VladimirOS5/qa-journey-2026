# BUG-001: Изображения товаров не соответствуют названиям для problem_user

**Severity:** Major  
**Priority:** Medium

## Описание
При входе под пользователем `problem_user` изображения товаров в каталоге не соответствуют их названиям и описаниям.

## Шаги воспроизведения
1. Открыть https://www.saucedemo.com/
2. Ввести логин: `problem_user`
3. Ввести пароль: `secret_sauce`
4. Нажать "Login"
5. Обратить внимание на изображения товаров в каталоге

## Ожидаемый результат
Изображение товара соответствует его названию и описанию (как у `standard_user`).

## Фактический результат
Изображения товаров заменены на фото собаки (Dog API) и не соответствуют названиям.

## Окружение
- Браузер: Chrome 126
- ОС: Windows 11
- Разрешение: 1920x1080

## Примечание
Это ожидаемое поведение для тестового пользователя `problem_user`, но в реальном проекте такой баг был бы критичным.
