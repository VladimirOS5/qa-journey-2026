# BUG-003: Ошибка при заполнении поля "Last Name" на checkout для problem_user

**Severity:** Critical  
**Priority:** High

## Описание
При оформлении заказа под пользователем `problem_user` заполнение поля "Last Name" вызывает ошибку / страница перестаёт отвечать.

## Шаги воспроизведения
1. Войти под `problem_user` / `secret_sauce`
2. Добавить товар в корзину
3. Перейти в корзину → Checkout
4. Заполнить поле "Last Name"

## Ожидаемый результат
Поле принимает ввод, можно продолжить оформление заказа.
