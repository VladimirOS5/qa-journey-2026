# Тест-кейсы: Неделя 1

## Приложение: https://demoqa.com/login

### TC_REG_01: Пароль короче 8 символов
- Приоритет: High
- Техника: Граничные значения
- Шаги:
  1. Открыть /register
  2. Ввести валидный email
  3. Ввести пароль из 7 символов
  4. Нажать Submit
- ОР: Сообщение "Пароль должен содержать минимум 8 символов"

### TC_REG_02: Валидная регистрация
- Приоритет: High
- Техника: Эквивалентные классы
- Шаги:
  1. Открыть /register
  2. Ввести валидный email
  3. Ввести пароль из 8+ символов
  4. Нажать Submit
- ОР: Успешная регистрация, редирект на /profile
